BAGIAN 1 — GAMBARAN BESAR & KEPUTUSAN DESAIN
================================================================================

KONSEP UTAMA:
  Trip = satu post/halaman detail perjalanan yang tampil di website.
  Berisi semua informasi yang dibutuhkan customer untuk memutuskan booking.

HIERARKI DATA MODUL TRIP:

  MASTER DATA (referensi):
  ├── trip_categories         (Umroh, Haji, Wisata Halal — kategori besar)
  │       └── trip_category_services (Umroh VIP, Umroh Plus, Haji Furoda — variasi)
  ├── destinations            (Arab Saudi, Turki, Bali, dll)
  ├── activities              (Snorkeling, Hiking, City Tour, dll)
  ├── difficulties            (Easy, Moderate, Hard)
  └── pricing_categories      (Dewasa, Anak-anak, Lansia — master global)

  TRIP (post utama):
  trips
  ├── trip_itineraries    (one-to-many — per hari, rich text)
  ├── trip_packages       (one-to-many — Double/Triple/Quad)
  │       └── trip_package_prices (one-to-many — harga per pricing_category)
  ├── trip_batches        (one-to-many — hanya untuk recurring trip)
  │
  └── PIVOT (many-to-many dengan master data):
      ├── trip_destination  (trips ↔ destinations)
      ├── trip_activity     (trips ↔ activities)
      └── trip_difficulty   (trips ↔ difficulties)
      (trip_type: FK langsung, 1 trip = 1 type)


KEPUTUSAN DESAIN:

1. TRIP CATEGORIES & SERVICES
   - trip_categories        = kategori besar (Umroh, Haji, Wisata Halal)
   - trip_category_services = variasi per kategori (Umroh VIP, Umroh Plus, dst)
   - Relasi: trip_categories (1) → trip_category_services (many)
   - Di form posting trip: pilih kategori dulu → service muncul otomatis
   - Keduanya wajib dipilih (NOT NULL di trips)
   - 1 trip hanya punya 1 kategori dan 1 service (FK langsung di trips)

2. DESTINATIONS, ACTIVITIES, DIFFICULTY
   - Many-to-many via pivot table
   - Contoh: Trip "Umroh + City Tour Istanbul" punya 2 destination
     (Arab Saudi & Turki) dan 2 activity (Ibadah Umroh & City Tour)

3. ITINERARY
   - Tabel terpisah trip_itineraries (bukan JSON)
   - Alasan: rich text per hari, bisa banyak, perlu query parsial
   - Sort order bisa diatur (drag & drop di admin)

4. FAQ
   - JSON di kolom trips.faq
   - Format: [{"question": "...", "answer": "..."}]
   - Alasan: selalu ditampilkan sekaligus, tidak perlu query individual

5. GALLERY & VIDEO
   - JSON di kolom trips
   - trips.gallery   : array path foto
   - trips.video_urls: array URL YouTube/Vimeo

6. PACKAGES (Double/Triple/Quad)
   - Tabel trip_packages (one-to-many dari trips)
   - 1 package punya banyak harga berdasarkan pricing_category
   - Harga fix per trip, tidak berubah per tanggal/batch

7. PRICING CATEGORIES (Dewasa/Anak/Lansia)
   - Master data global di tabel pricing_categories
   - Harga per kategori disimpan di trip_package_prices (many-to-many)

8. TRIP SCHEDULE: FIXED vs RECURRING
   - trips.trip_schedule enum('fixed', 'recurring', 'other')
   - Nama kolom trip_schedule (bukan trip_type) untuk hindari konflik naming
   - fixed    : departure_date & return_date di tabel trips
                quota_total di tabel trips
                team_leader_id di tabel trips
   - recurring: departure_date & return_date di trip_batches
                quota_total di trip_batches
                team_leader_id di trip_batches

9. TEAM LEADER
   - FK ke tabel staff (bukan users)
   - Butuh nama (user_profiles) + jabatan (staff.position) sekaligus
   - Filter hanya staff dengan work_status = 'active'

10. STATUS TRIP
    - Admin update manual dari dashboard
    - Perubahan status → fire TripStatusChanged / TripBatchStatusChanged event
    - Booking module mendengar event ini untuk cascade status booking

Schema::create('trips', function (Blueprint $table) {
    $table->bigIncrements('id');

    // ── Section General ──────────────────────────────────────────
    $table->string('title');
    $table->string('slug')->unique();
    $table->string('trip_code', 50)->unique()->nullable();
    // Format bebas, contoh: UMR-2026-001

    // Kategori besar — wajib dipilih
    $table->unsignedBigInteger('trip_category_id');
    // FK ke trip_categories (Umroh, Haji, Wisata Halal)

    // Variasi kategori — wajib dipilih setelah kategori dipilih
    $table->unsignedBigInteger('trip_category_service_id');
    // FK ke trip_category_services (Umroh VIP, Umroh Plus, dll)

    $table->integer('duration_days');
    $table->integer('duration_nights');
    // Contoh: 12 hari, 11 malam → "12D11N"

    // ── Trip Schedule: Fixed atau Recurring ──────────────────────
    $table->enum('trip_schedule', [
        'fixed',     // tanggal & kuota fix di sini
        'recurring', // tanggal & kuota ada di trip_batches
        'other'
    ])->default('fixed');

    // Hanya diisi jika trip_schedule = 'fixed'
    $table->date('departure_date')->nullable();
    $table->date('return_date')->nullable();
    $table->integer('quota_total')->nullable();
    $table->unsignedBigInteger('team_leader_id')->nullable();
    // FK ke staff.id

    // Untuk recurring: rentang waktu trip dibuka
    $table->date('open_from')->nullable();  // trip buka dari tanggal ini
    $table->date('open_until')->nullable(); // trip buka sampai tanggal ini

    // ── Section Overview ─────────────────────────────────────────
    $table->string('overview_title')->nullable();
    $table->longText('description')->nullable(); // rich text

    // Highlights
    $table->string('highlights_title')->nullable();
    $table->json('highlights')->nullable();
    // Format: ["Mengunjungi Masjidil Haram", "Ziarah Raudhah", ...]

    // ── Section Includes / Excludes ──────────────────────────────
    $table->string('include_title')->nullable();
    $table->json('includes')->nullable();
    // Format: [{"title": "Tiket Pesawat PP", "description": "..."}]

    $table->string('exclude_title')->nullable();
    $table->json('excludes')->nullable();
    // Format: [{"title": "Biaya Visa", "description": "..."}]

    // ── Section Map & Gallery ────────────────────────────────────
    $table->string('map_title')->nullable();
    $table->string('map_image')->nullable();    // path gambar peta
    $table->text('map_iframe')->nullable();     // embed iframe Google Maps

    $table->json('gallery')->nullable();
    // Format: ["uploads/trips/foto1.jpg", "uploads/trips/foto2.jpg"]

    $table->json('video_urls')->nullable();
    // Format: ["https://youtube.com/...", "https://vimeo.com/..."]

    // ── Section FAQs ─────────────────────────────────────────────
    $table->string('faq_title')->nullable();
    $table->json('faq')->nullable();
    // Format: [{"question": "...", "answer": "..."}]

    // ── Status & Visibility ──────────────────────────────────────
    $table->enum('status', [
        'draft',      // belum dipublish, tidak tampil di website
        'open',       // buka booking
        'full',       // kuota habis (otomatis via observer/event)
        'closed',     // tutup booking manual
        'ongoing',    // sedang berjalan → cascade ke bookings departed
        'completed',  // selesai → cascade ke bookings returned
        'cancelled'   // dibatalkan
    ])->default('draft');

    $table->boolean('is_published')->default(false);
    $table->string('thumbnail')->nullable();

    // ── Meta ─────────────────────────────────────────────────────
    $table->unsignedBigInteger('created_by')->nullable();

    $table->timestamps();
    $table->softDeletes();

    $table->foreign('trip_category_id')
        ->references('id')->on('trip_categories')->onDelete('restrict');
    $table->foreign('trip_category_service_id')
        ->references('id')->on('trip_category_services')->onDelete('restrict');
    $table->foreign('team_leader_id')
        ->references('id')->on('staff')->onDelete('set null');
    $table->foreign('created_by')
        ->references('id')->on('users')->onDelete('set null');

    $table->index('slug');
    $table->index('trip_code');
    $table->index(['trip_category_id', 'status']);
    $table->index(['trip_category_service_id', 'status']);
    $table->index(['status', 'is_published']);
    $table->index('departure_date');
    $table->index('trip_schedule');
});

EVENTS & LISTENERS MODUL TRIP
------------------------------------------------------------------------

EVENT YANG DIKIRIM (didengar Booking module):
  TripStatusChanged      (property: Trip $trip, string $oldStatus, string $newStatus)
  TripBatchStatusChanged (property: TripBatch $batch, string $oldStatus, string $newStatus)

EVENT YANG DITERIMA (dikirim Booking module):
  TripQuotaFull      → OnTripQuotaFull      → trips.status = 'full'
  TripBatchQuotaFull → OnTripBatchQuotaFull → trip_batches.status = 'full'


------------------------------------------------------------------------
CONTOH TripObserver — fire event saat status berubah
------------------------------------------------------------------------

// app/Modules/Trip/Observers/TripObserver.php
public function updated(Trip $trip): void
{
    if ($trip->isDirty('status')) {
        event(new TripStatusChanged(
            trip: $trip,
            oldStatus: $trip->getOriginal('status'),
            newStatus: $trip->status
        ));
    }
}

// app/Modules/Trip/Observers/TripBatchObserver.php
public function updated(TripBatch $batch): void
{
    if ($batch->isDirty('status')) {
        event(new TripBatchStatusChanged(
            batch: $batch,
            oldStatus: $batch->getOriginal('status'),
            newStatus: $batch->status
        ));
    }
}

   // Trip fixed:
   sisa = trips.quota_total - SUM(bookings.total_pax
          WHERE trip_id = x AND status != 'cancelled')

   // Trip recurring (per batch):
   sisa = trip_batches.quota_total - SUM(bookings.total_pax
          WHERE trip_batch_id = x AND status != 'cancelled')

   // Saat admin pilih team leader di form trip/batch:
