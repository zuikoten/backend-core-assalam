📋 PENJELASAN FILE/DIREKTORI PENTING
================================================================================

🔗 SYMLINK PUBLIC:
--------------------------------------------------------------------------------
File: config/filesystems.php
Konfigurasi:
    'links' => [
        public_path('storage') => storage_path('app/public'),
    ],

Artisan command: php artisan storage:link
Hasil: public/storage → storage/app/public

Fungsi: Membuat file di storage/app/public dapat diakses via URL /storage/...


📂 STORAGE LOCATION:
--------------------------------------------------------------------------------
Path helper                    → Lokasi actual
─────────────────────────────────────────────────────────
storage_path('app/private')    → storage/app/           (private, tidak bisa diakses via URL)
storage_path('app/public')     → storage/app/public/     (public, bisa diakses via /storage/... jika disymlink)
storage_path('framework')     → storage/framework/      (cache, sessions, views)
storage_path('logs')          → storage/logs/            (log files)


🛣️ API ROUTES:
--------------------------------------------------------------------------------
File: backend/app/Modules/AgentSystem/Routes/api.php

Route Groups:
1. PUBLIC ROUTES (tanpa auth):
   - POST /api/login              → Login
   - POST /api/forgot-password    → Lupa password
   - POST /api/verify-otp        → Verifikasi OTP
   - POST /api/reset-password     → Reset password
   - GET  /api/settings/registration-fee  → Ambil biaya registrasi
   - GET  /api/regions/provinces          → Get provinces
   - GET  /api/regions/regencies/{id}    → Get cities
   - GET  /api/regions/districts/{id}    → Get districts
   - POST /api/agents/register          → Registration step 1

2. PROTECTED ROUTES (auth:sanctum):
   - POST /api/logout
   - GET  /api/me
   - POST /api/email/send-otp
   - POST /api/email/verify
   - GET  /api/agents/{id}/status
   - POST /api/agents/{id}/documents     → Step 2
   - PUT  /api/agents/{id}/address       → Step 3
   - PUT  /api/agents/{id}/bank         → Step 4
   - POST /api/agents/{id}/payment       → Step 5

3. ADMIN ROUTES (auth:sanctum + admin middleware):
   - GET  /api/admin/dashboard
   - GET  /api/admin/pending-agents
   - PUT  /api/admin/documents/{id}/verify
   - PUT  /api/admin/payments/{id}/verify
   - PUT  /api/admin/agents/{id}/status


📦 MODULE SYSTEM:
--------------------------------------------------------------------------------
Package: 
- Laravel Framework v12
- Laravel Sanctum v4.3 (API Token Authentication)
- Laravolt Indonesia v0.41 (Data Wilayah Indonesia)

Struktur Module:
app/Modules/{ModuleName}/
├── Controllers/         → HTTP controllers
├── Models/             → Eloquent models
├── Providers/         → ServiceProvider (module registration)
├── Requests/          → Form request validation
├── Resources/         → API Resource (transformer)
└── Routes/            → Module routes

Module Registration (bootstrap/app.php):
    ->withProviders([
        AgentSystemServiceProvider::class,
    ])

Service Provider Features:
    - Load migrations from database/migrations
    - Register module routes
    - Register module configs


🔐 AUTHENTICATION:
--------------------------------------------------------------------------------
Method: Laravel Sanctum (Token-based)
- Guards: 'sanctum' (stateful), 'sanctum' (stateless API)
- Token table: personal_access_tokens
- Middleware: auth:sanctum

Admin Check:
- Middleware: 'admin' (EnsureUserIsAdmin)
- Field: users.is_admin (boolean)


📊 DATABASE:
--------------------------------------------------------------------------------
Default: SQLite (development)
Location: database/database.sqlite

Main Tables:
- users              → User account
- agents             → Data agent
- agent_addresses    → Alamat agent
- agent_documents    → Dokumen KTP
- agent_bank_accounts → Rekening bank
- payments           → Pembayaran registrasi
- regions            → Wilayah Indonesia
- otp_codes          → Kode OTP
- personal_access_tokens → API tokens
- admin_actions      → Log aktivitas admin
- settings           → Konfigurasi app


⚙️ MIDDLEWARE PENTING:
--------------------------------------------------------------------------------
1. EnsureUserIsAdmin (app/Http/Middleware/EnsureUserIsAdmin.php)
   → Cek user.is_admin = true
   → Digunakan untuk route admin

2. EnsureFrontendRequestsAreStateful (Laravel Sanctum)
   → CSRF protection untuk frontend SPA
