STRUKTUR_DATABASE (mengacu migration saat ini)
================================================

CATATAN UMUM
- Semua tabel adalah hasil database migrations di folder: database/migrations.
- Tipe field mengikuti definisi di migration (Laravel Schema Builder).
- Beberapa tabel standar Laravel disertakan (cache, jobs, sessions, personal_access_tokens, dll).
- Beberapa migration wilayah Indonesia menggunakan prefix table dari config('laravolt.indonesia.table_prefix').

------------------------------------------------
1) Laravel standard
------------------------------------------------

1.1 cache
- key (string, PK)
- value (mediumText)
- expiration (integer, index)

1.2 cache_locks
- key (string, PK)
- owner (string)
- expiration (integer, index)

1.3 jobs
- id (bigint, PK)
- queue (string, index)
- payload (longText)
- attempts (tinyint unsigned)
- reserved_at (uint unsigned nullable)
- available_at (uint unsigned)
- created_at (uint unsigned)

1.4 job_batches
- id (string, PK)
- name (string)
- total_jobs (int)
- pending_jobs (int)
- failed_jobs (int)
- failed_job_ids (longText)
- options (mediumText nullable)
- cancelled_at (int nullable)
- created_at (int)
- finished_at (int nullable)

1.5 failed_jobs
- id (bigint, PK)
- uuid (string, unique)
- connection (text)
- queue (text)
- payload (longText)
- exception (longText)
- failed_at (timestamp default current)

1.6 sessions
- id (string, PK)
- user_id (FK nullable -> users.id)
- ip_address (string(45) nullable)
- user_agent (text nullable)
- payload (longText)
- last_activity (int, index)

1.7 personal_access_tokens
- id (bigint, PK)
- tokenable_type/tokenable_id (morphs)
- name (text)
- token (string(64), unique)
- abilities (text nullable)
- last_used_at (timestamp nullable)
- expires_at (timestamp nullable, index)
- created_at/updated_at

1.8 otp_codes
- id (bigint, PK)
- user_id (FK nullable -> users.id)
- whatsapp (string(20))
- code (string(100))
- type (enum: reset_password, claim_account, phone_verify, login)
- is_used (boolean default false)
- used_at (timestamp nullable)
- expires_at (timestamp)
- created_at/updated_at
- Index: [whatsapp,type], expires_at

2.4 villages

3) Sistem user / authorization
------------------------------------------------

3.1 regions
- id (PK)
- region_type (enum: province, regency, district)
- code (string(10), unique)
- name (string(255))
- parent_id (FK nullable -> regions.id, onDelete set null)
- timestamps
- Index: parent_id, code, region_type

3.2 users
- id (PK)
- email (string unique)
- phone (string(20) unique nullable)
- whatsapp (string(20) unique nullable)
- password (string)
- status (enum: pending, active, inactive, suspended, rejected) default pending
- email_verified (boolean default false)
- email_verified_at (timestamp nullable)
- phone_verified (boolean default false)
- phone_verified_at (timestamp nullable)
- remember_token (string(100) nullable)
- last_login_at (timestamp nullable)
- last_login_ip (string(45) nullable)
- is_temporary_password (boolean default false)
- timestamps + softDeletes
- Index: email, phone, whatsapp, status

3.3 roles
- id (PK)
- name (string(50), unique)
- display_name (string(100) nullable)
- description (text nullable)
- is_active (boolean default true)
- timestamps
- (seed langsung di migration untuk role dasar)

3.4 user_roles
- id (PK)
- user_id (FK -> users.id, onDelete cascade)
- role_id (FK -> roles.id, onDelete cascade)
- assigned_at (timestamp nullable)
- assigned_by (FK nullable -> users.id, onDelete set null)
- timestamps
- Unique: [user_id, role_id]
- Index: user_id, role_id

3.5 user_profiles
- id (PK)
- user_id (unique, FK -> users.id, onDelete cascade)
- full_name (string)
- avatar (string nullable)
- birth_date (date nullable)
- gender (enum: L,P nullable)
- nationality (string(100) nullable default Indonesia)
- address (text nullable)
- city (string(100) nullable)
- province (string(100) nullable)
- postal_code (string(10) nullable)
- bio (text nullable)
- website (string nullable)
- social_media (json nullable)
- language (string(10) default id)
- timezone (string(50) default Asia/Jakarta)
- notification_email (boolean default true)
- notification_whatsapp (boolean default true)
- timestamps

3.6 staff
- id (PK)
- user_id (unique, FK -> users.id onDelete cascade)
- employee_id (string(20) unique nullable)
- position (string(100))
- department (string(100))
- join_date (date)
- end_date (date nullable)
- access_level (enum: viewer, operator, supervisor, manager) default operator
- supervisor_id (FK nullable -> staff.id, onDelete set null)
- employment_status (enum: full_time, part_time, contract, intern) default full_time
- work_status (enum: active, on_leave, resigned, terminated) default active
- notes (text nullable)
- timestamps + softDeletes
- Index: department, access_level, work_status

3.7 password_histories
- id (PK)
- user_id (FK -> users.id onDelete cascade)
- is_temporary (boolean default false)
- must_change (boolean default false)
- changed_at (timestamp nullable)
- timestamps
- Index: user_id

4) Agen & proses bonus
------------------------------------------------

4.1 agents

- Index: nik, agent_level, upline_id, registration_fee_status

4.2 agent_addresses

- district_id (FK -> regions.id)
- village (string(255) nullable)
- full_address (text)
- postal_code (string(10) nullable)
- is_domicile (boolean default true)
- timestamps
- Index: agent_id, province_id

4.3 agent_documents

- verification_status (enum: pending, approved, rejected) default pending
- rejection_reason (text nullable)
- timestamps
- Unique: [agent_id, document_type]

4.4 agent_bank_accounts

4.5 agent_payments
- id (PK)

- payment_method (enum: transfer, cash, virtual_account) default transfer

- status (enum: pending, success, failed, refunded) default pending

- timestamps

4.6 agent_bonus_payouts

4.7 agent_bonus_transactions

4.8 admin_actions
